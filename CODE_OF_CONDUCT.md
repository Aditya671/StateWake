# Code of Conduct

## Our standard

Participation in this project is expected to be respectful, constructive, and focused on the technical problem.

Unwelcome behavior includes harassment, personal attacks, intimidation, discrimination, and deliberately disruptive conduct.

Project maintainers may remove comments, commits, issues, or contributions that violate this standard.

## Enforcement

Report concerns privately to the project maintainer rather than escalating them in public issue threads.
