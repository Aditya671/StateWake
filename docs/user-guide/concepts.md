# Core Concepts

## Evidence

Evidence is an authoritative artifact or reference that supports a reliability claim.

## Evidence receipt

A receipt binds the expected identity and producer context of an externally supplied artifact to the artifact that was actually received.

## Provenance

Provenance explains where evidence came from and how it relates to upstream sources and execution.

## Reliability state

Reliability state is the authoritative state derived from verified evidence and recorded transitions.

## Reconciliation

Reconciliation records how a known discrepancy was addressed. A reconciliation is not considered proof merely because it completed successfully; it must be bound to the discrepancy and its supporting evidence.

## Attestation

An attestation is a portable reliability claim whose supporting evidence, state, and verification relationships can be independently checked.

## Proof bundle

A proof bundle packages the evidence and verification context required to inspect a reliability claim without relying on an in-memory application state.
