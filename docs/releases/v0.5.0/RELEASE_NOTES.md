# StateWake v0.5.0 Release Notes

**Status:** historical GitHub release/tag, published 6 October 2026 at commit `e26db67c3e590012eae8b5f705a8b6fcc8039101`. This record is retained for provenance and must not be reused or moved for the v0.5.1 candidate. The current source artifact does not claim that v0.5.0 was published to PyPI.

## Historical release boundary

The v0.5.0 GitHub release extended StateWake's evidence model into operational trust while preserving public API contract version `1` and Python `>=3.11,<3.14`. Its release record covered:

- privacy-aware evidence admission and evidence-governance controls;
- historical signing-trust interpretation;
- append-only human approval lifecycle with revocation/supersession semantics;
- publication authorization bound to exact source, verification evidence, target registry, and distribution bytes;
- independent PyPI/TestPyPI registry read-back and continuing registry lifecycle observations;
- native SDK qualification across the maintained integration families;
- bounded read/review surfaces and the optional StateWake UI;
- expanded release-trust evidence and the StateWake v0.5.0 technical white paper.
