# StateWake v0.2.0

## Release boundary

v0.2.0 is the cybersecurity capability release. It completes the StateWake cybersecurity progression through V3 Tier 15.

## Included security capabilities

- Tier 4 — Security Assurance
- Tier 5 — Continuous Security Assurance
- Tier 6 — Recovery & Resilience Assurance
- Tier 7 — Trust-Domain & Anchor Assurance
- Tier 8 — Supply-Chain & Release Assurance
- Tier 9 — Evidence-Portability & Independent Verification Assurance
- Tier 10 — Assurance Operations & Security Decision Automation
- Tier 11 — Identity-Bound Access & Least Privilege
- Tier 12 — Runtime & Hostile-Input Containment
- Tier 13 — Data Lifecycle & Confidentiality Protection
- Tier 14 — Security Incident Evidence & Forensic Continuity
- Tier 15 — Cryptographic Longevity & Trust Migration

The V3 architecture identifies Tier 15 as its deliberate stopping boundary. The release adds backward-compatible security capabilities and security-facing integration surfaces; it does not redefine the public API contract version.
