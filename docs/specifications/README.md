# Specification Classification

These specifications are historical engineering references unless explicitly marked otherwise.

- **Active V1 specification** — governs current product behavior.
- **Supporting-producer compatibility specification** — documents an integration boundary whose producer remains authoritative.
- **Historical reference** — preserved for engineering provenance only and not a roadmap commitment.

When a specification describes retired orchestration, scheduling, watchdog, distributed-worker, control-plane, or historical AgentContract behavior, treat it as historical reference unless the current architecture explicitly reactivates that boundary.
